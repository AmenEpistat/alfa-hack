# Хакатон — Альфа-Бизнес

Проект для прототипа хакатона.

Контекст кейса: персонализированные бизнес-инсайты внутри Альфа-Бизнеса на основе аналитики банка и внешних источников. В `client` создан прототип React + TypeScript + MobX + Ant Design с архитектурой FSD и стилями Sass: меню, главная с карточкой инсайта и подробный разбор на учебных данных.

## Структура

- [client/README.md](client/README.md) — запуск и структура React-приложения.
- `src/` — первоначальная пустая папка проекта.
- `assets/` — место для ресурсов прототипа.
- [docs/design-references.md](docs/design-references.md) — найденные публичные материалы по интерфейсу Альфа-Бизнеса с датами и ограничениями актуальности.
- [docs/learning-plan.md](docs/learning-plan.md) — план изучения пяти открытых вопросов с доски, материалы и практические задания.
- [docs/metrics-review.md](docs/metrics-review.md) — разбор обновлённых метрик с Holst и план измерений.

Создан 21 октября 2026 года.
