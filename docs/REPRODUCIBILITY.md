# Фиксация версий

Основной путь запуска — Docker Compose через `sh scripts/start.sh synthetic` или `sh scripts/start.sh live`. Docker Compose должен поддерживать `up --wait --wait-timeout` (2.20+). API собирается для `linux/amd64`, включая запуск на ARM через эмуляцию.

| Компонент | Механизм фиксации |
| --- | --- |
| Python 3.12 | Digest базового образа в `docker/backend.Dockerfile`; метаданные выбранного образа указывают Python 3.12.15 |
| Node.js 22 | Digest образа сборщика в `docker/frontend.Dockerfile`, фиксирующий также точный patch-релиз внутри образа |
| nginx 1.28 | Digest runtime-образа в `docker/frontend.Dockerfile` |
| SearXNG | Digest в основном и самостоятельном Compose-файлах |
| Python-пакеты | `docker/requirements.lock`: точные версии и SHA256; установка `pip --require-hashes` |
| Клиентские пакеты | `client/package-lock.json`: версии и integrity; установка `npm ci` |
| Альтернативное окружение Nix | `flake.lock` фиксирует ревизии входов `flake.nix` |

Digest образов прочитаны из публичного реестра Docker 26 октября 2026 года. Изменение тега в реестре не обновит закреплённый образ автоматически. При обновлении нужно заменить digest, пересобрать образы и повторить проверки. Python-lock обновляется `sh docker/update-lock.sh` с установленным uv; клиентский lock — средствами npm с последующей проверкой сборки. Старый `ranking_module/requirements.lock` не используется основной Docker-сборкой.

Не закреплены снимком: apt-репозиторий Debian и устанавливаемые OCR-пакеты, ревизии моделей Hugging Face, ответы внешнего LLM-шлюза, RSS и поисковых систем. Модели заданы именами `intfloat/multilingual-e5-small` и `cross-encoder/mmarco-mMiniLMv2-L12-H384-v1`; их веса не входят в поставку. Поэтому живой конвейер не заявлен как побитово воспроизводимый или автономный.

Синтетический стенд воспроизводит проверяемые результаты без скачивания моделей и вызовов внешних сервисов после сборки. UUID, время генерации и пути артефактов не фиксированы. Для полностью изолированной поставки заранее соберите и сохраните образы; репозиторий сам по себе не содержит пакеты и базовые образы.
