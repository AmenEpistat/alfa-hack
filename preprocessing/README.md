# Preprocessing

CSV преобразуется в очищенные записи компаний и признаки. Групповые показатели вычисляются
по всему очищенному датасету до выбора компании. Итог — JSON company_profiles.
preprocess_csv(path, company_ids=[id], cache_dir=...) сохраняет полный датасет и отдельные
выборки в постоянный кеш; изменение содержимого, delimiter или кода инвалидирует записи.
Используется из backend.py. Runtime не требует pandas, ноутбука или графиков.
